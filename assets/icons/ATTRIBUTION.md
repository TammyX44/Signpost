# Bundled logos

| File | Product | Source | License |
|---|---|---|---|
| `claude.svg` | Claude Code (Anthropic) | [Simple Icons](https://simpleicons.org) v13.21.0 | CC0 1.0 |
| `openai.svg` | Codex (OpenAI) | [Simple Icons](https://simpleicons.org) v13.21.0 | CC0 1.0 |
| `ollama.svg` | Ollama | [Simple Icons](https://simpleicons.org) v13.21.0 | CC0 1.0 |

CC0 covers the SVG files, not the brands. The logos are trademarks of their owners and are used only to
identify the program that is actually running in a workspace. If you represent one of these brands and
want a logo removed, open an issue and it will be removed.

Agents without a bundled logo use the generic ✦ glyph. To use your own logo, put `<name>.svg` or
`<name>.png` in `~/.config/signpost/icons/` (for example `openai.svg` replaces the bundled Codex logo).
